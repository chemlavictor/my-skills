# my-skills

Skills d'agent personnels.

## Skills

| Skill | Description |
|---|---|
| [infra-graph-multiagent](infra-graph-multiagent/SKILL.md) | Explore un repo inconnu avec un workflow multi-agent et produit un document d'infrastructure en Markdown avec graphiques Mermaid : machines/hosts et ce que chacun exécute, stockage disque, bases de données internes et externes, et tous les points d'entrée (ports, webhooks, queues, SFTP, cron, pushes tiers) — chaque fait rattaché au fichier qui le prouve. À utiliser quand l'utilisateur veut cartographier, documenter, auditer ou comprendre l'infra d'un repo, demande « que contient mon repo / où sont les serveurs / où sont stockées les données / qui parle à qui », veut un schéma d'architecture, ou mentionne docker-compose, ansible, terraform, kubernetes, nginx, bases de données ou stockage dans un codebase qu'il ne connaît pas bien. Se déclenche aussi sur des demandes en français comme « graph d'infra », « schéma d'infrastructure », « cartographie du repo », « documenter l'infra », même sans le mot « skill » ni « mermaid ». |
